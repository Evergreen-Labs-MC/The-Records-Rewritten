### ⚠️ Important Notice

- The latest release now includes both Bedrock and Java editions, plus an additional edition. Please visit the **Versions** or **Changelog** tab to download the one you need. All files are clearly labelled.
- This pack is best used alongside **Jukebox Custom Disc Fix** by eclipseisoffline.
- Minecraft may warn that this pack was made for an older version of the game. This is expected, and the pack will still work. It requires no additional mods or dependencies, only a standard Minecraft installation.
- To see the full list of songs included, open the **Versions** tab and select your preferred version.

### Installation

**Modrinth App**
It is not recommended that you download this inside of the Modrinth App, as you need to extract the files out of the .zip, instead, download from the Github page or from the Modrinth Website and extract the actual, working zip.

**Github**
Download a version from our Official Github Page (above). If it is the latest version and the file is named, 'Inside of me!', then you need to extract the file contents.

**Modrinth Website**
1. Click the download button and save the file.
2. Open Minecraft, go to Settings → Resource Packs, and drag and drop the file into the pack folder.
3. Select the pack from the list and confirm the prompt if Minecraft warns that it was made for an older version.
4. If the pack does not appear, restart Minecraft. If it still does not appear, try downloading the file again.

Earlier versions of the pack remain available on the **Versions** tab. This pack is actively maintained and will continue to receive updates.
